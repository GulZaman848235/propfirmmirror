Questions

Where do these prop firm discount codes come from?

Only from the firms themselves. Each code is published on the firm's own website, checkout page, help centre or announcement page, and each one links to the page it came from with the date it was checked. Prop Firm Mirror never lists affiliate, creator, partner or comparison-site codes.

Why is my prop firm promo code not working?

Firms change and end offers often, and many codes apply only to certain programs, account sizes or first purchases. Check the terms listed with the code and the firm's own offer page. Prop Firm Mirror hides a code once its end date passes or if it has not been re-checked within seven days, but a firm can still end an offer early, so confirm the price at checkout.

Are prop firm discount codes only for new customers?

Some are. A firm may limit a code to a first purchase, to certain programs or account sizes, or to a date range. Each code on this page lists what it applies to and any end date the firm publishes, so check those terms before you buy.

Do the codes change the prices shown on Prop Firm Mirror?

Only where the firm's own page confirms exactly which accounts a code covers. In the interactive comparison, a percentage code then shows the price after the code, with the list price struck through. Codes for bundles, resets or unclear offers never change a price and appear only as a badge.

Does Prop Firm Mirror earn money from these codes?

No. Every code here is the firm's own public code, not an affiliate code, and the site has no affiliate links. Firms cannot pay to be listed, and any personal or commercial tie between Prop Firm Mirror and a firm is disclosed on that firm's page.

How often are the codes checked?

Codes are re-checked on the firms' own pages as part of the rolling daily check, and firms with a code about to end are added to that day's check. A code is hidden once its end date passes or if it has not been confirmed within the last seven days, and each one shows the date it was last checked.
